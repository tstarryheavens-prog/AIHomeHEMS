## 📡 1. 宅内スマート機器の自動スキャン：IP手打ち地獄からの解放

家庭内IoTの導入で一番の挫折ポイントになるのが、**「機器のIPアドレスってどこで調べるの？」** 問題です。

ルーターの管理画面にログインしてDHCP払い出し一覧を開き、「どれが蓄電池でどれがテレビだ……？」と頭を抱えた経験は誰にでもあるはず。

<br>

そこで今回、日本のスマートホーム共通規格である**「ECHONET Lite」のUDPマルチキャスト探索機能**をゼロからPythonソケットで実装しました！

<br>

```
[ あなたのPC / NAS ]
       │
       ▼  UDP マルチキャスト送信 (224.0.23.0 : 3610)
   「誰か ECHONET Lite 機器はいませんかー？ (EPC 0xD6 問い合わせ)」
       │
 ┌─────┴─────────────────────────┐
 ▼                               ▼
[ 蓄電池 (パナソニック/オムロン) ]   [ エコキュート / エアコン ]
 「はーい！私は蓄電池(0x027D)です！」   「給湯器(0x026B)です！」
```

<br>

### 探索の心臓部コード（マルチキャスト電文生成）

ECHONET Lite規格では、マルチキャストアドレス `224.0.23.0:3610` に対して以下の電文を投げると、ネットワーク内のすべての対応家電が一斉に応答を返してくれます。

```python
# network_scanner.py より抜粋
ECHONET_MULTICAST_ADDR = "224.0.23.0"
ECHONET_PORT = 3610

# 電文構造: EHD1(0x10) EHD2(0x81) TID(0x0001) SEOJ(コントローラ 0x05FF01) 
#          DEOJ(ノードプロファイル 0x0EF001) ESV(Get 0x62) OPC(1) EPC(自インスタンスリスト 0xD6) PDC(0)
req_frame = bytes([
    0x10, 0x81, 0x00, 0x01, 
    0x05, 0xFF, 0x01, 
    0x0E, 0xF0, 0x01, 
    0x62, 0x01, 0xD6, 0x00
])

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM, socket.IPPROTO_UDP)
sock.setsockopt(socket.IPPROTO_IP, socket.IP_MULTICAST_TTL, 2)
sock.sendto(req_frame, (ECHONET_MULTICAST_ADDR, ECHONET_PORT))
```

<br>

さらに、ニチコン等の独自TCPポート（3610 / 1369）や、既存HEMSコントローラーのHTTP（ポート80）、ネットワークカメラ（ATOMCam RTSP）もマルチスレッドで並行スキャン！

<br>

画面上の **「🔍 宅内ネットワークを自動スキャンする」** ボタンをポチッと押すだけで、宅内の機器がズラリと一覧表示され、**「🔋 蓄電池として登録」「🔌 HEMSとして登録」** ボタンを押すだけで設定が瞬時に完了します。もはや魔法です。

## 🇯🇵 2. 国内主要メーカー蓄電池へのマルチベンダー対応（TCP/UDPハイブリッド）

我が家で動いていたニチコン蓄電池は、実は業界でも珍しい「TCP/IPソケット」によるECHONET Lite通信を採用していました。

しかし！パナソニック（創蓄連携）、オムロン（KPBP-A）、ダイヤゼブラ電機/旧田淵電機（EneTelus）、シャープ（クラウド蓄電池）、京セラ（Enerezza）など、**国内の9割以上のメーカーは「UDP 3610」が標準仕様**です。

<br>

「ニチコン専用のTCPクライアント」のままでは、他のメーカーで動くはずがありません。

そこで、通信プロトコルを完全に隠蔽・抽象化する**`UniversalEchonetClient`** を新規設計しました。

<br>

### ハイブリッド通信アーキテクチャ

```
            [ AI 最適化スケジューラー & 監視ロガー ]
                           │
             UniversalEchonetClient (統一I/F)
             ├── get_full_system_info()  -> SOC, 充放電W, PV発電W
             └── set_battery_mode()      -> 充電/放電/待機/自動
                           │
       ┌───────────────────┴───────────────────┐
       ▼                                       ▼
【 TCP 接続ハンドラー 】                【 UDP 接続ハンドラー 】
  ・ニチコン ESS / V2H T5                 ・パナソニック (創蓄連携)
  ・ポート 3610 / 1369                    ・オムロン (KPBP-A)
  ・ハードウェアタイマー同期 (0xC3/0xC4)   ・シャープ / ダイヤゼブラ / 京セラ
                                         ・標準ECHONET 蓄電池 (0x027D)
```

<br>

蓄電池の残量（EPC `0xE7`）、充放電電力（EPC `0xD3`）、運転モード（EPC `0xDA`）などのプロパティコードはエコーネット規格で共通化されているため、通信レイヤー（TCP or UDP）を吸収してやるだけで、**パナソニックでもオムロンでもシャープでも、まったく同じAI制御アルゴリズムがそのまま動く**ようになりました！

<br>

実機をお持ちでない開発者やテスターの方のために、リアルな発電・消費シミュレーションを行う「デモ・シミュレーションモード」も完備しています。

## ⚡ 3. 全国10大電力会社 ＆ 新電力プランのプリセット化

電気代を極限まで下げるAI制御の肝は、**「深夜の超割安時間帯（ナイトタイム）にどれだけ安く充電し、昼間の超高額時間帯（デイタイム）を蓄電池でどれだけ逃げ切るか」** にあります。

<br>

しかし、このナイトタイムの時間帯は電力会社やプランによってバラバラです。

- **中部電力「スマートライフ【夜とく】」**: 21:00 〜 翌朝 07:00 （10時間）
- **東京電力「スマートライフ」**: 01:00 〜 翌朝 06:00 （わずか5時間！）
- **関西電力「はぴｅタイムＲ」**: 23:00 〜 翌朝 07:00 （8時間）
- **東北電力「よりそう＋ナイト10」**: 22:00 〜 翌朝 08:00 （10時間）
- **新電力・市場連動型（JEPX連動）**: 30分ごとに市場価格がダイナミック変動

<br>

これをユーザーに手動計算させるのは酷すぎます。

そこで、全国主要10大電力会社＋新電力の料金プランマスター（[`presets_jp.py`](https://github.com/tstarryheavens-prog/AIHomeHEMS/blob/main/presets_jp.py)）を作成！

<br>

プルダウンで自分の電力会社とプランを選ぶだけで：
- **深夜割安時間帯の開始・終了時刻**
- **昼夜の買電単価（円/kWh）**
- **バッテリー劣化を防ぐJIT最適充電時間帯（例: 03:00〜06:30）**

がミリ秒で自動セットされます！もちろん、ご自宅の契約に合わせて数値を1円単位・1分単位で自由にカスタマイズ可能です。

## ⚙️ 4. 設定画面のWeb GUI化：ブラウザだけで全てが完結！

これまでは `config.yaml` をテキストエディタで開いて編集する必要がありました。

「インデントがずれてYAMLパースエラーで起動しない」「パスワードに特殊文字が入ってクラッシュした」……そんな悲劇を根絶するため、Streamlitのダッシュボードに**第5のタブ「⚙️ システム設定・汎用化」** を新設しました！

<br>

### 実際のUI構成

1. **📡 1. 宅内スマート機器 自動スキャン ＆ 一括検出**
   - ワンクリックでLAN内スキャン → 機器カードからワンタップで設定反映
2. **🔋 2. 蓄電池 / V2H メーカー ＆ 接続設定**
   - 日本国内主要メーカーをプルダウン選択（仕様説明や推奨設定を自動ガイド）
   - バッテリー容量（kWh）や保護SOC下限・上限のスライダー調整
3. **⚡ 3. 電力会社 ＆ 電気料金プラン設定**
   - 電力会社選択 → プラン選択で時間帯・単価を自動補完
   - FIT満了日（カレンダーピッカー）、FIT買取単価、卒FIT単価の設定
4. **☀️ 4. 太陽光発電 ＆ 系統（買電/売電）取得方式**
   - HEMS Web取得、スマートメーターBルート（Wi-SUN）、ECHONETメータ等の切り替え
5. **📍 5. 設置地域 ＆ 日射量予測（気象API）設定**
   - 全国47都道府県・主要都市プルダウンで緯度・経度を自動セット
6. **💾 設定の安全保存 ＆ タイムスタンプ付き自動バックアップ**
   - 「保存して即時反映」ボタンで、現在稼働中のロガーやAIスケジューラーにホットリロード！

<br>

設定ファイルを直接触る必要はもう一切ありません。スマホのSafariやChromeからポチポチ入力するだけで、完全にあなたの家専用のAI HEMSが完成します。
